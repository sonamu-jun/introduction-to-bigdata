# Optional After-Class Practice

*These lessons provide optional practice after the 75-minute class.*

You may skip every lesson in this folder. The next class begins from the required material in `01-2_Python_Basics_II` and does not assume that you completed these notebooks.

| Lesson | Optional focus |
| --- | --- |
| Tuples | A tuple stores a short, fixed-position record. |
| Sets | A set represents uniqueness and supports set operations. |
| Comprehensions | A comprehension rewrites a simple loop in compact notation. |
| Classes | A class defines a small object with state and behavior. |

Each notebook supports a top-to-bottom run, one changed value, and a one-sentence explanation of the result.
