# Retained Reference Data

The current notebook does not read any file from this `input/` folder. Its lesson values are created directly in code.

The data files remain as reference copies because existing paths are fixed. No input upload is required to run this lesson. Their originals are the [Palmer Penguins dataset release](https://doi.org/10.5281/zenodo.3960218) and the [Wikimedia Commons image record](https://commons.wikimedia.org/wiki/File:Galapagos_Penguin.jpg).

Provenance, schemas, checksums, and limitations are documented in the course data catalog.
