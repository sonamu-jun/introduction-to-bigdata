# Weekly Study Summary Problem

*A synthetic study log needs one reproducible weekly summary without making claims about real students.*

*Estimated prepared-cell time: 10–15 minutes.*

## Setting

Five records describe a day, subject, study duration, and whether the planned session was completed.

## Analytical Question

The summary must preserve the source rows, total hours by subject, the number of completed sessions, and an overall completion label.

## Given Data

| Day | Subject | Hours | Completed |
| --- | --- | ---: | --- |
| Mon | Python | 1.5 | True |
| Tue | Statistics | 2.0 | True |
| Wed | Python | 1.0 | False |
| Thu | Data | 2.5 | True |
| Fri | Python | 2.0 | True |

## Constraints

The solution must use core lists, dictionaries, Boolean conditions, loops, and one function. Tuple unpacking, comprehensions, classes, and external packages are not required.

## Required Output

The executed notebook must display the five records, a subject-hours dictionary, a returned weekly-summary dictionary, and a labeled completion result. The practice notebook applies Boolean Rules and Branching, Collections and Iteration, and Functions and Object State.
