# Campus Event Budget Problem

*A student team must calculate an itemized cost estimate for a small campus data event.*

*Estimated prepared-cell time: 10–15 minutes.*

## Setting

The event is named **Data Night**. The team expects 48 attendees, receives 18,000 KRW per attendee, pays 500,000 KRW for the room, and budgets 6,500 KRW of refreshments per attendee.

## Analytical Question

The team needs the expected ticket income, refreshment cost, total cost, and remaining budget in one labeled report.

## Given Data

| Variable | Value | Unit |
| --- | ---: | --- |
| Expected attendees | 48 | people |
| Fee per attendee | 18,000 | KRW per person |
| Room cost | 500,000 | KRW |
| Refreshment cost | 6,500 | KRW per person |

## Constraints

The calculation must use descriptive variables, arithmetic expressions, and formatted text available in Python Basics I. Collections and conditional branches are outside this case.

## Required Output

The executed notebook must show the named inputs, each derived amount with its unit, and one final line that reports the event name and budget balance. The practice notebook applies Values, Names, and Numeric Types and String Structure and Transformation.
