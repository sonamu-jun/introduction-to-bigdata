# Optional After-Class Practice

You may skip every lesson in this folder. The next class begins from the required material in `02-1_Python_Basics_III` and does not assume that you completed these notebooks.

| Lesson | Optional focus |
| --- | --- |
| Binary Files | The lesson compares text bytes with a serialized Python record. |
| Image Files | The lesson opens, annotates, and saves a derived image. |

Each notebook supports a top-to-bottom run and inspection of its generated file while keeping the original input unchanged.
